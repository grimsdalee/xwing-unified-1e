C-ROC diagnostic ventral geometry provenance
=============================================

The diagnostic mesh croc-donor-ventral-test.obj contains ventral bow and
ventral aft geometry derived from:

Title: SW - C-ROC Gozanti Class Freighter
Author: Astrofossil
Source: https://www.thingiverse.com/thing:2996102
Archived source package:
https://archive.org/download/thingiverse-2996102/SW_-_C-ROC_Gozanti_Class_Freighter_2996102.zip

The source work is licensed under the Creative Commons
Attribution-NonCommercial 3.0 Unported licence (CC BY-NC 3.0):
https://creativecommons.org/licenses/by-nc/3.0/

Changes made for this diagnostic:

- Selected only the source model's ventral bow and ventral aft components.
- Transformed the geometry to the Unified First Edition C-ROC coordinate space.
- Reused nearest-surface UV references from the existing C-ROC TTS model so
  the diagnostic additions use the existing C-ROC texture.
- Combined the additions with the unchanged original faces of the existing
  repository C-ROC model.

This diagnostic derivative is provided under CC BY-NC 3.0 and is intended
only for non-commercial testing and restoration of the First Edition C-ROC
miniature used by this project.
